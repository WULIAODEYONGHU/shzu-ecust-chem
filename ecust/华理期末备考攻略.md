# 华理期末备考攻略

> 华东理工大学 · 化工相关专业 期末复习总攻略

## 适用科目
化工原理、反应工程、过程设备、物理化学、化工热力学、分离工程等。

## 复习时间线（建议）
- **T-4 周**：过一遍课件与教材，整理知识框架
- **T-2 周**：刷课后题与往年真题，标记高频考点
- **T-1 周**：专题突破（计算大题 + 公式默写）
- **考前 2 天**：错题回顾 + 公式卡片

## 分科攻略
- **化工原理**：计算题为王（精馏、吸收、传热），熟记操作线与设备公式
- **反应工程**：三类理想反应器设计方程 + 动力学，RTD 与多选
- **过程设备**：设备结构与选型，压力容器强度概念
- **物理化学 / 热力学**：推导 + 定义，图表（T-S、p-V）要会看

## 资料来源
- 课程群 / 学习委员整理的往年卷
- 图书馆教参与习题集
- 本仓库 `ecust/` 与 `shared/` 下的笔记

## 答题技巧
- 计算题：写清「公式 → 代入 → 单位 → 结果」
- 简答题：先定义后展开，画图辅助
- 先易后难，预留检查时间
