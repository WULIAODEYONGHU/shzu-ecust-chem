# 化工工艺学

> 石河子大学 · 化工工艺学 课程笔记 / 资料整理

## 课程简介
化工工艺学研究化工生产过程的原理、流程与操作，涵盖典型大宗化工产品（无机、有机、石化、煤化工）的工艺路线、反应条件、设备选型与节能优化。

## 核心章节
- 化工工艺基础：物料衡算、能量衡算、工艺流程图（PFD / PID）
- 无机工艺：硫酸、合成氨、氯碱（电解食盐水）、纯碱
- 有机 / 石化工艺：石油炼制、乙烯、甲醇、聚合工艺
- 煤化工：煤气化、煤制烯烃
- 工艺设计与安全环保（HAZOP、绿色化工）

## 重点概念 / 公式
- 转化率、选择性、收率
- 单耗、能耗与公用工程
- 反应温度 / 压力对平衡与速率的影响
